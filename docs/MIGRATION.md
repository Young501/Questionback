# 换电脑与备份

## 同步范围

GitHub 保存代码、原始 PDF、内置内容、整理目录和预览图。新电脑 clone 后首次启动会自动加入内置学习包。

浏览器内作答、收藏、错题、每日轮次、当前加练、网页保存文本，以及仅手动导入的新题库不在项目目录，git push/pull 不会同步。当前没有云端同步或多设备进度合并。

## 完整迁移步骤

1. 旧电脑用原来的浏览器打开 http://127.0.0.1:4173/。
2. 点击「导出完整备份」，获得拾题完整备份-日期.json。普通学习包导出不含个人进度与收藏。
3. 自行将完整备份传到新电脑。不要提交到公开仓库；默认命名的完整备份和 backups/ 已被 gitignore 排除。
4. 新电脑 clone 仓库，安装 Node.js 20+，运行 node server.cjs，用固定浏览器打开同一地址。
5. 若新电脑已有个人数据，先导出它的完整备份。
6. 「资料与导入 → 恢复浏览器备份」选择旧电脑备份，核对数量并确认替换。
7. 检查收藏、题库、笔记、进度。日期变化后今日复习按新日期处理，旧记录仍保留。

恢复是整体替换，不是合并。多电脑轮流使用时以最新记录为准，避免旧备份覆盖新进度。

## 更新代码

先在目录运行 git status，处理本地修改后再运行 git pull --ff-only。启动服务并刷新页面。兼容更新会保留浏览器存储。

地址、端口、浏览器或浏览器配置不同，会读到不同的存储。localhost 与 127.0.0.1 也不同。看似丢失时先回原浏览器和原地址检查，无痕窗口及清理网站数据也会影响保存。
